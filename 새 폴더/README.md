# 모두의 건축공학

입문자를 위한 건축공학 학습 웹입니다. 건축기사 시공 범위의 **CPM(주공정법)** 개념·네트워크 실습·객관식과 기초 과목을 함께 둡니다.

- `#/cpm/walk/basic` 한 단계씩 따라 계산하기
- `#/cpm/practice/basic` 결합점을 가린 표 채점
- `#/cpm/crash/basic` 공기 단축 실험
- `#/cpm/lab` 자작 네트워크 계산기

## 실행

브라우저에서 `index.html`을 열면 됩니다.

로컬 서버를 쓰려면:

```powershell
python -m http.server 5173
```

그다음 `http://localhost:5173`으로 접속합니다.
