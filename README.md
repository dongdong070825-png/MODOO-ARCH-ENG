# CPM 주공정법

공정표를 처음 보는 학생을 위한 CPM 학습 페이지입니다. 다른 건축 과목은 다루지 않습니다.

1. `#/cpm/learn/schedule` 기초 강의. 작업, 결합점, ES·EF, 공기, LS·LF, TF·FF, 주공정, 더미
2. `#/cpm/walk/basic` 따라 계산하기
3. `#/cpm/play/basic` 한 칸 도전
4. `#/cpm/practice/roll` 표 채점. 들어올 때마다 다른 공정표가 나옵니다
5. `#/cpm/draw` 작업 목록을 보고 결합점, 화살표, 더미로 공정표를 직접 그린 뒤 표를 채웁니다
6. `#/notes` 오답노트. 해설을 보고 넘어간 칸과 틀린 객관식만 모입니다
7. `#/glossary` 용어사전

## 실행

브라우저에서 `index.html`을 열거나, 로컬 서버를 띄웁니다.

```powershell
python -m http.server 5173
```

그다음 `http://localhost:5173`으로 접속합니다.
